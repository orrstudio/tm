# QEYBƏT ALLAHIN QADAĞAN ETDİYİ BİR ƏMƏLDİR

Sizcə qeybət nədir? Sizə qarşı səhv edən birini başqasına pislədiyiniz zaman qeybət olur.  


- Allah qeybəti sevmir.  
- Qeybət edilməsini istəmir.  
- Və qeybəti qadağan edir.  


Hucurat surəsinin 12-ci ayəsində Allah buyurur:  


«Zənn sizə haram edilmişdir. Hansınız ölmüş qardaşınızın ətini yemək istəyər?».  


Allah ayətdə deyir ki, qeybət etdiyimiz zaman ölmüş qardaşımızın ətini yemiş kimi oluruq.  


![qeybet](/assets/pictures/qeybet.png)  


— Bəs sizə pislik edəni kimə danışmalısınız?  
— Əlbəttə ki, Allaha.  


Çünki Allaha söylədiyiniz zaman:  


- Allah qəlbinizə rahatlıq verər.  
- Dərəcat itirməzsiniz.  
- Dərəcat qazanırsanız.  
- Allah çözüm gətirər.  


Sizə edilən pisliyi istədiyiniz pis sözlərlə Allaha danışsanız  (ürəyinizi boşaltsanız) belə, günah qazanmazsınız (dərəcə itirməzsiniz). Çünki müraciət etdiyiniz məqam Allahdır.
